# Dashboard launcher artwork

`boxart.png` is the unmodified native Dashboard Home capture also shown as
`docs/screenshots/dashboard.png` in xboxllr. Capture: October 21, 2026, using
owner-supplied Dashboard 5960 files and the shared native runtime.

Original Xbox Dashboard interface, artwork and Xbox marks belong to Microsoft.
This capture identifies the supported title; it is not a separately licensed
Microsoft asset pack. The project's source license does not relicense the
depicted interface. No firmware, Dashboard executable or content tree is included.
